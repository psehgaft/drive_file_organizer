# Drive Organizer

Capa personal de administración e inteligencia sobre Google Drive: índice propio de metadatos, búsqueda rápida, diagnóstico de nombres, duplicados y permisos — sin copiar los archivos y, en el MVP, **sin escribir nada en Drive**.

Nace del proyecto de renombrado descriptivo del 2026-11-12 (1,199 archivos corregidos a mano sobre un Drive de 25,340 archivos y 3,716 carpetas): el nombre solo no basta para organizar un archivo así; hace falta una herramienta.
